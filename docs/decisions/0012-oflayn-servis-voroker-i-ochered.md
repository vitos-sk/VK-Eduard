# 0012. Офлайн — сервис-воркер, очередь в IndexedDB и кэш экранов

**Дата:** 2026-10-05
**Статус:** принято; реализует [0003](0003-oflayn-cherez-ochered.md)

## Контекст
На объекте связь пропадает. Нужно открыть приложение и внести время без сети, не потеряв запись.

## Решение
- **Сервис-воркер** (`public/sw.js`, без библиотек): статика — сначала кэш, страницы — сначала сеть с запасной копией, запасная страница `/offline.html`; прогрев главной, «Годин» и формы времени.
- **Очередь** новой записи времени в IndexedDB (собственная обёртка, без Dexie), ключ идемпотентности `client_id`, отправка напрямую из браузера в `work_entries` (идентификатор серверного действия меняется при деплое).
- **Кэш данных экранов**: показываем сохранённое, затем свежее.
- Не пытались сделать офлайн для всего: отчёты с фото, правки и создание объектов остаются онлайн (дорого и рискованно по конфликтам).

## Последствия
- На iPhone нет фоновой отправки: очередь уходит, когда приложение открыто.
- При выходе из аккаунта копии страниц и данные стираются; очередь привязана к пользователю.
- Сервис-воркер подключается только в боевой сборке.
