# 0013. Офлайн для всех экранов: прогрев по списку, версия воркера = сборка, миниатюры на телефоне

**Дата:** 2026-10-21
**Статус:** принято; продолжает [0012](0012-oflayn-servis-voroker-i-ochered.md)

## Контекст
После ADR 0012 без сети открывались только три страницы из ~30: воркер заранее сохранял `/`, `/hours`, `/time/manual`, а страницы, которые человек видел переходом внутри приложения, в кэш не попадали (воркер ловит только адресные переходы, а нажатие на вкладку — запрос данных Next). Версия воркера была ручной константой: файл не менялся между деплоями, старые файлы копились. Фото без сети — пустые квадраты.

## Решение
- **Прогрев по списку** основных экранов (`lib/offline/warm-paths.ts`): воркер сам скачивает страницу, из её HTML и CSS достаёт скрипты и шрифты, из HTML — ссылки на миниатюры. Плюс «недавние» страницы-детали (30 последних, вытесняются). Кэшировать сами RSC-ответы не стали: их формат меняется между версиями Next, а полная перезагрузка из кэша быстрая и надёжная.
- **Версия воркера = номер сборки**: `/sw-version.js` (route handler) подключается через `importScripts`; браузер обновляет воркер, если изменился любой подключённый скрипт. Старые копии удаляются только после полного прогрева новых.
- **Миниатюры** (`site-photos`, `avatars`) кэшируются по пути файла без токена подписи, запрос в режиме `cors`, потолок 600 файлов. **Фото отчётов (`entry-photos`) не кэшируются**: по решению автора они остаются полноценными онлайн и пропадают без сети.
- **Честный интерфейс:** время копии на плашке (метка `vk-saved-at` в `<head>` сохранённой страницы), `NetworkButton` для действий, которым нужна сеть, `SafeImg` с заглушкой вместо битого значка, умная `offline.html`.
- Без библиотек (как в 0012). Запасной вариант, если список файлов из прогрева окажется неполным: Serwist (`@serwist/turbopack`) строит список из сборки.

## Последствия
- Данные без сети — на момент последнего захода онлайн; поэтому на плашке стоит время копии.
- На телефоне до выхода из аккаунта лежат копии страниц (зарплата, чаты, дашборд шефа) — при выходе стираются вместе с миниатюрами.
- Прогрев и «недавние» страницы дают серверу дополнительные рендеры (раз в 6 часов на экран и на страницу-деталь).
- Не проверено вживую в связке с настоящим приложением: гидрация React с лишним `<meta>` в `<head>` и поведение на реальных iPhone/Android — по чек-листу в `docs/PWA.md`, раздел 7.
