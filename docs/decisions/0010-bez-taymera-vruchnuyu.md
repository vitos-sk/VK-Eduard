# 0010. Без таймера смены — время вносится вручную

**Дата:** 2026-10-05
**Статус:** принято; заменяет часть [0002](0002-odna-zapis-vremya-obyazatelno.md)

## Контекст
Таймер («Почати роботу / Завершити», пауза) требовал открытой смены и постоянного состояния на всех экранах, а рабочие в итоге вносили время вручную — забыли нажать, закрыли позже и т.д. Это усложняло код и добавляло ошибки (незакрытые смены, перерыв «в процессе»).

## Решение
Убрать таймер целиком. Единственный способ внести время — «Додати час»: дата, начало, конец, перерыв (кнопками), объект, описание. Работает офлайн через очередь.

## Последствия
- Из приложения убраны старт/стоп смены, пауза, окно «Де ви сьогодні працювали?» и общий контекст открытой смены.
- В базе остались `source = timer` и поддержка открытой смены у старых записей; новых таких нет.
- Допустима смена через полночь (22:00 → 06:00), длительность 1 мин – 18 ч.
