# 0005. Тёмно-зелёная тема вместо тёмно-серой

**Дата:** 2026-09-07
**Статус:** принято (решение человека по макету)

## Контекст
Прототип собран в тёмно-серой теме (`--bg: #0A0A0C`) с жёлтым акцентом. Присланный
макет — тёмно-зелёный с тем же жёлтым.

## Решение
Меняем значения 12 токенов в `:root` файла `globals.css`. Семантические имена,
структура и компоненты не трогаются. Приглушённые цвета текста делаем зеленоватыми
(`#9DB394`, `#7E9675`), а не нейтрально-серыми.

## Почему
1. Токены заводились именно для этого — перекраска стоит правки одного файла.
2. Нейтральный серый на зелёном фоне выглядит грязным; подмешанный зелёный делает
   интерфейс цельным.
3. Приглушённые токены подняли по светлоте относительно серой темы: приложением
   пользуются на улице, подписи таб-бара должны читаться на солнце.

## Чем платим
Ничем, если в компонентах нет захардкоженных цветов. Это надо проверить грепом до
начала работ, а не после.

## Что рассматривали ещё
Не рассматривали — цвет задан макетом.
