# Push-напоминание «внесите отчёт»

**Цель:** каждый день в 18:00 по Брюсселю рабочим (не шефам) приходит уведомление «создайте отчёт»; нажатие открывает `/reports/new`.

**Решения**
- Канал — Web Push (VAPID) через сервис-воркер `public/sw.js`. iPhone: только установленное приложение (iOS 16.4+).
- Планировщик — `pg_cron` в Supabase, два запуска (`16:00` и `17:00` UTC); приложение пропускает тот, где в Брюсселе не 18-й час (`schedule.ts`). Vercel Cron на Hobby не даёт точного времени.
- Получатели: активный профиль, роль не `boss`, нет `site_reports` на сегодняшнюю дату (по Брюсселю), на устройство не слали сегодня (`push_subscriptions.last_sent_on`).
- Подписка — строка на устройство (`push_subscriptions`, миграция `0020`); запись только сервером (перенос между аккаунтами на общем телефоне), читать/удалять свои может сам человек (RLS).
- Включение — переключатель на «Налаштування → Сповіщення» (разрешение спрашиваем по нажатию). `PushSync` тихо восстанавливает подписку после выхода/входа и смены языка, если разрешение дано и человек не выключал.
- Выход из аккаунта отвязывает подписку устройства (`OfflineReset`), чтобы на общем телефоне напоминание не уходило прежнему владельцу.
- Безопасность: `/api/cron/report-reminder` — только с `Authorization: Bearer CRON_SECRET` (нет секрета → закрыто); прокси этот путь не трогает.
- Проверка: `?dry=1` (никому не слать, только посчитать), `?force=1` (игнорировать «сейчас не 18:00»).
- Ошибки доставки: 404/410 → подписка удаляется; прочие считаются в `failed`, не роняют рассылку. TTL уведомления 2 часа.

**Не входит:** выходные/праздники (шлём каждый день, как просили), напоминание о «времени» (`work_entries`), уведомления шефу.
