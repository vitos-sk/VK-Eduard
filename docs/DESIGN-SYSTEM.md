# Дизайн-система «K group» — зелёная тема

Замена серой темы из `PLAN.md` §3. Структура токенов та же, меняются значения.
**Ни один компонент не должен знать хекс-код** — только семантические имена.

Навигация и набор табов **не меняются**. Меняются цвета, добавляется welcome-экран
и перерабатывается содержимое «Звітів».

---

## 1. Цвета

Тёмная тема единственная. Светлой нет, переключателя нет.

| Токен | Было (серая) | Стало (зелёная) | Где применяется |
|---|---|---|---|
| `--bg` | `#0A0A0C` | **`#0D2B08`** | фон всего приложения — цвет с фирменного логотипа |
| `--surface` | `#131418` | **`#1D3418`** | карточки, поля, таб-бар |
| `--surface-2` | `#1B1D22` | **`#26421F`** | вложенные блоки, неактивные сегменты, скелетоны |
| `--border` | `#25272C` | **`#2F5227`** | границы 1px |
| `--brand` | `#FFC93C` | **`#F5C43C`** | жёлтый: FAB, главные кнопки, активная вкладка, кольцо |
| `--brand-ink` | `#0A0A0C` | **`#0D2B08`** | текст поверх жёлтого — всегда тёмный |
| `--text` | `#FFFFFF` | `#FFFFFF` | заголовки, основной текст |
| `--text-muted` | `#8E9099` | **`#9DB394`** | подписи, даты, метаданные |
| `--text-dim` | `#5C5E66` | **`#7E9675`** | неактивные иконки таб-бара |
| `--success` | `#4ADE80` | **`#7BC96F`** | «Відпрацьовано», «в роботі» |
| `--warning` | `#FBBF24` | **`#F5C43C`** | «Перерва», «Додатково», «на паузі» |
| `--danger` | `#F87171` | **`#F2705F`** | ошибки |

Почему `--text-muted` зеленоватый, а не нейтрально-серый: на зелёном фоне серый
выглядит грязным. Подмешанный зелёный делает интерфейс цельным.

`--text-dim` подняли по светлоте относительно серой темы намеренно: приложением
пользуются на улице при ярком солнце, подписи таб-бара должны читаться. Оба
приглушённых токена дают на `--bg` контраст ≥ 4.5:1.

Фоны бейджей — цвет статуса с прозрачностью 14%, текст — сам цвет на полной непрозрачности.

### Как перекрашиваем

Все токены живут в одном месте — `:root` в `src/app/globals.css`. Перекраска = правка
12 строк, компоненты не трогаются. Перед этим проверить, что в компонентах нет
захардкоженных цветов:

```
grep -rE '#[0-9a-fA-F]{3,8}|bg-\[#|text-\[#' src/components src/app
```

Всё, что найдётся, — сначала переводим в токен, потом красим.

Без изменений: радиусы 16/14/8/12, поля экрана 16px, зазор между карточками 12px,
кнопка 56px, поле 52px, safe-area сверху и снизу.

`--surface-2`, заливка `--brand`, старт сверху, скруглённые концы. Показывает
отношение отработанного к дневной норме.

## 4. Экраны

### 4.1 Welcome — `/` (новый, публичный)

Единственный экран без логина. Вошедший пользователь редиректится в `(app)`.

- Логотип «K group.» крупно
- Заголовок «Робота. Просто. Чітко.»
- Пять пунктов с иконками в круглой обводке `--border`:
  Запис робочих годин · Опис виконаної роботи · Додавання фото · Додаткові години ·
  База даних для шефа
- Жёлтая кнопка «Почати роботу» → `/login`
- Блок установки PWA: на Android кнопка «Встановити», на iOS текстовая инструкция

Единственный экран, который имеет смысл рендерить на сервере — он статичный.

### 4.2 Головна — без структурных изменений

Перекрашивается. Опционально добавляется карточка «Сьогодні» с кольцом прогресса
из макета — она информативнее текущего голого таймера, но это не обязательно для
первого этапа.

### 4.3 Об'єкти — без изменений

Перекрашивается. Позже карточка объекта становится кликабельной и ведёт на
`/objects/[id]`.

### 4.4 Години — улучшаем, не ломаем

Экран остаётся как есть: таймер, периоды День / Тиждень / Місяць, сводка, график,
детали, ручной ввод. Что улучшаем:

- **таймер переживает перезагрузку** — состояние берётся из открытой записи в базе
  (`ended_at is null`), а не из React-стейта;
- «Завершити роботу» закрывает запись и предлагает «Додати опис» — прямой мост
  к «Звітам»;
- периоды считают реальные суммы из базы, а не моки;
- график по дням недели — из тех же данных.

### 4.5 Звіти — перепроектируем целиком

Подробно в отдельном документе: [REPORTS.md](REPORTS.md). Коротко:

- вкладки «Мої» / «Команда» (вторая — только `boss`);
- фильтры: Усі / Без опису / З фото, поиск, сводка часов по видимой выборке;
- три состояния карточки: Триває · Без опису · Готовий;
- детальная страница `/reports/[id]` с галереей и дозаполнением;
- форма `/reports/new` с подстановкой последнего объекта и быстрым вводом времени.

### 4.6 Ще / профиль

Куда-то должны попасть выход, профиль и управление людьми для шефа. Навигацию не
трогаем, поэтому вход — иконка профиля в шапке «Головної».

| `home/WorkTimeCard` | остаётся; опционально дополняется кольцом прогресса |

Удалять почти нечего. Основная работа — токены, экран «Звіти» целиком, детальная
страница и welcome.
