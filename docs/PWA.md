# PWA и работа без интернета

**Состояние:** по коду, октябрь 2026. Цель — приложение ставится на домашний экран, открывается без адресной строки и позволяет **добавить время даже без сети**. Магазины приложений не используются.

## 1. Манифест

`src/app/manifest.ts` (Next генерирует `/manifest.webmanifest`). Название «VK group», язык — по языку интерфейса (манифест читается без куки, поэтому у уже установленного приложения остаётся язык первой установки), `display: standalone`, `orientation: portrait`, цвета из токена `paper` (`#f3ecdc`) — чтобы запуск не вспыхивал белым.

## 2. Иконки и стартовые экраны

Все файлы собирает `npm run icons` (`scripts/generate-app-icons.mjs`) из знака «K» в `components/brand/Logo.tsx` — руками не правим.

| Файл | Для чего |
|---|---|
| `icons/icon-192/512/1024.png` | Android, общий случай |
| `icons/maskable-192/512.png` | Android режет под форму лаунчера (знак мельче, в центральном круге 80%) |
| `icons/shortcut-*.png` | быстрые действия по долгому нажатию на ярлык (Години, Новий звіт, Додати час) |
| `apple-touch-icon.png` (180) | iOS, без прозрачности |
| `splash/<W>x<H>.png` | стартовые экраны iOS для 12 размеров (`src/lib/pwa.ts`) |

Safari не читает `background_color` из манифеста, поэтому без стартовых картинок запуск встречает белым экраном — список устройств в `lib/pwa.ts` и в генераторе держим синхронными.

## 3. Установка

- **Android (Chrome):** «Установить приложение» из меню или баннера.
- **iPhone (Safari):** «Поделиться → На экран Домой». Приложение показывает подсказку на `/welcome`. Режим и статус-бар задаются метатегами `appleWebApp` (iOS манифест не читает).

## 4. Сервис-воркер (`public/sw.js`, `public/sw-lib.js`)

Подключается только в боевой сборке и только после входа (`ServiceWorkerRegister` внутри `AppShell`). Чистая логика (разбор файлов из HTML и CSS, ключи, вытеснение) лежит в `sw-lib.js` и покрыта тестами (`lib/offline/sw-lib.test.ts`); сам `sw.js` тонкий.

**Версия = номер сборки.** `sw.js` подключает `/sw-version.js` (route handler, `VERCEL_GIT_COMMIT_SHA`, локально — время запуска). Каждый деплой даёт новый номер, браузер видит обновление воркера. `/sw.js` и `/sw-lib.js` отдаются без кэширования (`next.config.ts`), `/sw-version.js` — тоже (`no-store`); прокси (`proxy.ts`) все три не трогает, иначе у вышедшего из аккаунта обновление получило бы редирект на `/welcome`.

| Что | Стратегия |
|---|---|
| `/_next/static/*`, иконки, шрифты | сначала кэш (файлы с хэшем не меняются) |
| Страницы (переходы по адресу) | сначала сеть; нет сети — последняя сохранённая копия; нет копии — `/offline.html`. Если копия есть, а сеть молчит дольше 2,5 с или сервер ответил 5xx — показываем копию; поздний ответ всё равно сохраняется |
| Миниатюры: фото объектов (`site-photos`) и аватары (`avatars`) | сначала кэш; ключ — путь файла **без токена подписи**; запрос к Storage идёт в режиме `cors` (непрозрачные ответы Chrome считает в квоте по ~7 МБ каждый); потолок 600 файлов, лишние (самые старые) удаляются |
| **Фото отчётов (`entry-photos`)** | **не кэшируются**: онлайн показываются как есть и в полном качестве, без сети — заглушка |
| `/api/*`, остальные запросы к Supabase, любые не-GET | не перехватываются |

**Прогрев** (`warmPathsFor` в `lib/offline/warm-paths.ts`): через ~4 секунды после загрузки (раз в 6 часов, при возврате сети, если копии устарели, и сразу после выхода новой версии) воркер по одной скачивает все основные экраны: «Головна», «Об'єкти», «Години», зарплата, «Звіти», чаты, чеклисты, «Налаштування» и их подстраницы, «Додати час», «Новий звіт»; шефу ещё дашборд, команду и настройки фирмы. Вместе со страницей сохраняются её скрипты и стили, шрифты из CSS и миниатюры, ссылки на которые есть в странице. Календарь грузится отдельным куском — его подтягивает `preloadCalendar`. В режиме экономии трафика (`saveData`) прогрева нет.

**«Недавние» страницы** (`isSnapshotPath`): когда человек открыл объект, отчёт, чат или чеклист онлайн, через 2 секунды воркер сохраняет копию. Хранится 30 последних; основные страницы прогрева не вытесняются. Цена: один лишний серверный рендер такой страницы, не чаще раза в 6 часов на страницу.

**Обновление версии.** Воркер новой версии сам просит приложение сделать прогрев (`sw-updated`). Старые копии удаляются **только когда новые основные страницы сохранены целиком**; пока нет — работают старые, иначе сохранённая страница осталась бы без своих скриптов.

**Очистка:** при заходе на `/welcome` или `/login` (то есть после выхода) страницы всех версий и миниатюры стираются; прогрев, который шёл в этот момент, кэш заново не наполнит. Статика остаётся (личных данных в ней нет). Приложение также просит у телефона постоянное хранилище (`navigator.storage.persist()`), чтобы кэш не выбрасывали при нехватке места.

Каждая сохранённая копия страницы получает в `<head>` метку `vk-saved-at`: по ней экран знает, что открыт из памяти телефона, и показывает время копии.

`public/offline.html` — запасная страница «Немає зв'язку» на языке из куки `locale`: с логотипом и кнопками на **реально сохранённые** разделы (читает Cache Storage воркера).

## 5. Очередь «Додати час» без сети

`lib/offline/outbox.ts` + IndexedDB (`lib/offline/idb.ts`, без внешних библиотек).

1. Нет сети (или запрос оборвался) → запись кладётся в очередь на телефоне вместе с `client_id`, пользователь видит «Збережено на пристрої».
2. Баннер «Не відправлено: N» вверху экрана.
3. Отправка (`OfflineSync`): при запуске, при возврате сети (`online`), при возврате на вкладку и раз в 30 с, пока очередь не пуста. Уходит **напрямую из браузера** в таблицу `work_entries` (а не серверным действием: у серверных действий идентификатор меняется при каждом деплое, и застрявшая очередь не смогла бы уйти).
4. Уникальный `client_id` не даёт задвоить: если запись уже дошла, а ответ потерялся, повтор считается успехом.
5. Сервер отверг запись (не «нет сети») — после 5 попыток она помечается «не удалось отправить» с кнопкой «Видалити».

**Границы:** офлайн работает только для **новой записи времени**. Правка записей, отчёты с фото, создание объектов требуют сети. На iPhone нет фоновой отправки — очередь уходит, когда приложение открыто.

## 6. Кэш данных экранов

`lib/offline/cache.ts`: «Години», дашборд, «Команда», калькулятор сначала показывают сохранённую копию, потом свежие данные. Копии в памяти и IndexedDB, ключ с id пользователя, срок 14 дней; сбрасываются после записи нового времени или отчёта и при выходе. Это даёт мгновенное открытие повторных экранов и чтение последних данных без сети.

## 6а. Как это выглядит без сети

- **Плашка** вверху: «Немає зв'язку…», а если страница открыта из копии — вторая строка «Показано збережене: 14:32» (или «20 жовтня, 14:32»). Время нужно, чтобы понимать, насколько данные устарели.
- **`NetworkButton`** (`components/ui/network-button.tsx`): кнопки, которым нужен интернет (отправка отчёта, сохранение объекта и имени, отправка в чат, загрузка фото), без сети неактивны, под ними «Потрібен інтернет». Запись времени работает без сети через очередь и остаётся обычной `Button`.
- **`SafeImg`** (`components/shared/SafeImg.tsx`): `Thumb`, `CardPhoto` и `Avatar` вместо битого значка показывают сцену, иконку или инициалы, если картинка не загрузилась. Ошибку, случившуюся до гидрации (страница открыта из копии без сети), ловит проверка `complete` и `naturalWidth` после монтирования.

## 7. Чек-лист приёмки

- [ ] Ставится на Android из Chrome, иконка не обрезана
- [ ] Ставится на iPhone через «Поделиться», иконка не чёрная, при запуске нет белой вспышки
- [ ] Запускается без адресной строки, шапка и нижняя панель не заезжают под «чёлку»
- [ ] В авиарежиме открываются все основные экраны из нижнего меню и «Налаштування» (после одного захода онлайн и паузы на прогрев, ~30 секунд)
- [ ] Без сети видны логотип, шрифт, нижнее меню, последние данные и плашка «Показано збережене: …»
- [ ] Миниатюры объектов и аватары видны без сети; фото внутри отчётов — нет (заглушка), с сетью — в полном качестве
- [ ] Страница, которую ни разу не открывали, показывает «Немає зв'язку» со ссылками на сохранённые разделы
- [ ] Без сети кнопки «відправити звіт», «зберегти», фото и отправка в чате неактивны с подписью «Потрібен інтернет"
- [ ] В авиарежиме запись времени сохраняется, помечена «не відправлено», при возврате сети уходит без дубля
- [ ] После выхода из аккаунта чужие данные не остаются на телефоне
- [ ] Новый деплой подхватывается после перезапуска приложения; после него без сети по-прежнему всё открывается
- [ ] После выхода из аккаунта в `Application → Cache Storage` нет `vk-pages-*` (кроме `/offline.html`) и `vk-thumbs`
