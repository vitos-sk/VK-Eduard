# PWA и работа без интернета

**Состояние:** по коду, октябрь 2026. Цель — приложение ставится на домашний экран, открывается без адресной строки и позволяет **добавить время даже без сети**. Магазины приложений не используются.

## 1. Манифест

`src/app/manifest.ts` (Next генерирует `/manifest.webmanifest`). Название «VK group», язык — по языку интерфейса (манифест читается без куки, поэтому у уже установленного приложения остаётся язык первой установки), `display: standalone`, `orientation: portrait`, цвета из токена `paper` (`#f3ecdc`) — чтобы запуск не вспыхивал белым.

## 2. Иконки и стартовые экраны

Все файлы собирает `npm run icons` (`scripts/generate-app-icons.mjs`) из знака «K» в `components/brand/Logo.tsx` — руками не правим.

| Файл | Для чего |
|---|---|
| `icons/icon-192/512/1024.png` | Android, общий случай |
| `icons/maskable-192/512.png` | Android режет под форму лаунчера (знак мельче, в центральном круге 80%) |
| `icons/shortcut-*.png` | быстрые действия по долгому нажатию на ярлык (Години, Новий звіт, Додати час) |
| `apple-touch-icon.png` (180) | iOS, без прозрачности |
| `splash/<W>x<H>.png` | стартовые экраны iOS для 12 размеров (`src/lib/pwa.ts`) |

Safari не читает `background_color` из манифеста, поэтому без стартовых картинок запуск встречает белым экраном — список устройств в `lib/pwa.ts` и в генераторе держим синхронными.

## 3. Установка

- **Android (Chrome):** «Установить приложение» из меню или баннера.
- **iPhone (Safari):** «Поделиться → На экран Домой». Приложение показывает подсказку на `/welcome`. Режим и статус-бар задаются метатегами `appleWebApp` (iOS манифест не читает).

## 4. Сервис-воркер (`public/sw.js`)

Подключается только в боевой сборке и только после входа (`ServiceWorkerRegister` внутри `AppShell`). Версионируется константой `VERSION` — старые кэши удаляются при активации. Заголовки `/sw.js` (без кэширования) заданы в `next.config.ts`, чтобы после деплоя телефоны не сидели на старой версии.

| Что | Стратегия |
|---|---|
| `/_next/static/*`, иконки, шрифты | сначала кэш (файлы с хэшем не меняются) |
| Страницы (переходы по адресу) | сначала сеть; нет сети — последняя сохранённая копия; нет копии — `/offline.html`. Если копия есть, а сеть молчит дольше 4 с — показываем копию |
| `/api/*`, запросы к Supabase, любые не-GET | не перехватываются |

**Прогрев:** через ~4 секунды после загрузки (раз в 6 часов) воркер заранее сохраняет `/`, `/hours` и `/time/manual` вместе с их скриптами, а страница подгружает и календарь — чтобы они открылись без сети с первого раза.

**Очистка:** при заходе на `/welcome` или `/login` (то есть после выхода) страницы и данные прежнего пользователя стираются.

`public/offline.html` — запасная страница «Немає зв'язку» на языке из куки `locale`.

## 5. Очередь «Додати час» без сети

`lib/offline/outbox.ts` + IndexedDB (`lib/offline/idb.ts`, без внешних библиотек).

1. Нет сети (или запрос оборвался) → запись кладётся в очередь на телефоне вместе с `client_id`, пользователь видит «Збережено на пристрої».
2. Баннер «Не відправлено: N» вверху экрана.
3. Отправка (`OfflineSync`): при запуске, при возврате сети (`online`), при возврате на вкладку и раз в 30 с, пока очередь не пуста. Уходит **напрямую из браузера** в таблицу `work_entries` (а не серверным действием: у серверных действий идентификатор меняется при каждом деплое, и застрявшая очередь не смогла бы уйти).
4. Уникальный `client_id` не даёт задвоить: если запись уже дошла, а ответ потерялся, повтор считается успехом.
5. Сервер отверг запись (не «нет сети») — после 5 попыток она помечается «не удалось отправить» с кнопкой «Видалити».

**Границы:** офлайн работает только для **новой записи времени**. Правка записей, отчёты с фото, создание объектов требуют сети. На iPhone нет фоновой отправки — очередь уходит, когда приложение открыто.

## 6. Кэш данных экранов

`lib/offline/cache.ts`: «Години», дашборд, «Команда», калькулятор сначала показывают сохранённую копию, потом свежие данные. Копии в памяти и IndexedDB, ключ с id пользователя, срок 14 дней; сбрасываются после записи нового времени или отчёта и при выходе. Это даёт мгновенное открытие повторных экранов и чтение последних данных без сети.

## 7. Чек-лист приёмки

- [ ] Ставится на Android из Chrome, иконка не обрезана
- [ ] Ставится на iPhone через «Поделиться», иконка не чёрная, при запуске нет белой вспышки
- [ ] Запускается без адресной строки, шапка и нижняя панель не заезжают под «чёлку»
- [ ] В авиарежиме открываются главная, «Години», «Додати час» (после одного захода онлайн)
- [ ] В авиарежиме запись времени сохраняется, помечена «не відправлено», при возврате сети уходит без дубля
- [ ] После выхода из аккаунта чужие данные не остаются на телефоне
- [ ] Новый деплой подхватывается после перезапуска приложения
