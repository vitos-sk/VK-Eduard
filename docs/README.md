## Зафиксированные решения человека

- Навигация из пяти табов (Головна / Об'єкти / **+** / Години / Звіти) **не меняется**
- «Години» — улучшаем, не ломаем; «Звіти» — перепроектируем целиком
- Вход: шеф заводит аккаунт, работник входит по email и паролю
- Офлайн обязателен: запись должна сохраняться без сети
- Ролей две: `worker` и `boss`. Шеф ничего не подтверждает
- SEO не нужно — приложение целиком за логином
